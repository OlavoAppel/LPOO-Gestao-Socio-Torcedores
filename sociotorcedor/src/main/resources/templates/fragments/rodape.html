Esporte Clube Ventania é um clube fictício, fundado em 1931 por funcionários de um campo de aviação, daí a biruta no brasão. Foi criado para o trabalho de Linguagem de Programação Orientada a Objetos do IFSul. Os escudos dos adversários pertencem aos respectivos clubes e aparecem aqui só para fins educacionais.
